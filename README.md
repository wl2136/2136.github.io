# Renewable Product AND TCSC-AI Website

A professional website for the independent, non-profit research institute "Renewable Product AND TCSC-AI".

## Overview

This website provides a clear and informative overview of the institute, suitable for a professional context. It showcases the institute's mission, research focus, activities, and collaboration opportunities.

## Features

- **Modern, Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Navigation**: Easy-to-use navigation with smooth scrolling
- **Professional Layout**: Clean, organized sections presenting all key information
- **Interactive Elements**: Hover effects and scroll animations for enhanced user experience

## Structure

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Interactive features and smooth scrolling

## Sections

1. **Home/Hero**: Introduction to the institute
2. **About**: Overview of the institute's mission and nature
3. **Research**: Focus areas (Renewable Products, AI, TCSC-AI)
4. **Activities**: Core activities and outputs
5. **Collaboration**: Partnership and employment information
6. **Contact**: Contact information and inquiries

## Usage

Simply open `index.html` in a web browser to view the website. No additional setup or dependencies required.

## Customization

The website uses CSS variables for easy color customization. Modify the `:root` variables in `styles.css` to change the color scheme.
